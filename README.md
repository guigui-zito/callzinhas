# Chamadinhas

Este repositório guarda só os instaladores do Chamadinhas e os arquivos que o app usa para se atualizar sozinho.

## Baixar

Abra [Releases](https://github.com/guigui-zito/chamadinhas/releases/latest) e baixe o instalador do seu sistema:

- **Windows**: `Callzinhas_<versão>_x64-setup.exe` (ou o `.msi`).

Os instaladores ainda não têm assinatura de código: o Windows pode mostrar o aviso do SmartScreen. Clique em
*Mais informações → Executar assim mesmo*.

## Atualizações

Com a opção ligada nas configurações, o app confere este repositório ao abrir e a cada 24 horas. Ele só instala
pacotes assinados pela chave do projeto.
